# ADO-1681 — Update .github organization profile as a first-party surface index

## Goal
Update the GitHub organization profile (`profile/README.md` — this worktree is the `.github` repo,
so the file that the bundle calls `.github/profile/README.md` lives at repo-root `profile/README.md`)
so it acts as a concise first-party index of approved public XrmGhost surfaces for visitors,
crawlers, and LLMs.

## Scope and changes
- Edited `profile/README.md` only.
- Replaced the informal bullet list under "Where to go" with a compact Markdown table acting
  as an explicit surface index (Surface | What you'll find there).
- Added a one-line framing sentence ("This profile is an index, not the story...") to
  differentiate the profile's role from the website/docs, per the constraint against
  duplicating long-form narrative.
- Kept existing hero, positioning paragraphs, "The pieces", and "Where this is going" sections
  untouched — only the destination index was rewritten.
- No other files touched (no assets, no other repos).

### Surfaces included in the new index
Confirmed via `gh repo list xrmghost --json name,visibility,url` that the org's public repos are:
`xrmghost`, `xrmghost-docs`, `xrmghost-skills`, `xrmghost-attributes`, `.github`. Combined with the
two public first-party websites already referenced (`www.xrmghost.tech`, `docs.xrmghost.tech`),
the index now lists:

1. `www.xrmghost.tech` — product overview/positioning
2. `docs.xrmghost.tech` — getting-started guides and CLI reference
3. `github.com/xrmghost/xrmghost` — main public repo, issues/feature requests
4. `github.com/xrmghost/xrmghost-skills` — public agent skills repo
5. `github.com/xrmghost/xrmghost-attributes` — public declarative-attributes library
6. `github.com/xrmghost/xrmghost-docs` — docs-site source repo

No gated/admin surface (e.g. `admin.xrmghost.tech`) was added or referenced. All other org repos
(`xrmghost-cli`, `xrmghost-core`, `xrmghost-akms-functions`, `xrmghost-user-portal`,
